# Crowned Dogs

Пошаговые дуэли Персон — боевых андроидов, которыми управляют операторы. Постсоветские регионы, база в соляной шахте, бой с выбором атаки прямо на враге. Игра работает в браузере, отдельном окне Windows и Telegram.

**Локальная сборка Windows и браузера:** [запуск, установка Rust и устройство проекта](LOCAL_BUILD.md). `npm run local:build` создаёт две программы в `release-local/Crowned-Dogs/`; `npm run web:build` — браузерную папку в `apps/web/dist/`.

**Совместная работа и деплой:** [CONTRIBUTING.md](CONTRIBUTING.md) — ветки и Pull Request для двух разработчиков, проверки и одна безопасная команда обновления VPS.

Концепт игры (сеттинг, правила, оружие, стиль): [документ](https://claude.ai/artifact/F5ZwmpZkDkQiYptP9DvEgc).

## Что уже есть

- **Боевое ядро Rust** (`crates/game-core`). Правила хода, оружие, погода, время суток, сжатие поля, таймер, бот-соперник. Баланс и каталог: `crates/game-core/catalog/catalog.json`. Клиент и сервер вызывают одно ядро через WASM; `packages/core/src/` сохраняет типизированный интерфейс. Сервер хранит сетевой бой и бросает кости.
- **Веб-клиент** (`apps/web`). Бой с ботом в 3D: нарисованный цех, живые фигуры, атака прямо по телу врага, музыка и звуки. Считает те же правила ядра, что и бот.
- **Telegram-бот** (`apps/server`). Новый игрок сначала подписывает контракт и получает жетон с номером вида K-417-093. Этот номер и есть ID игрока. Дальше бой с ботом и дуэль с другом по ссылке. Приказы тайные, на ход 60 секунд, кнопки прямо в чате.
- **Звук** (`packages/audio`). Выстрелы, попадания, щит, шаги, граната, нож, интерфейс, фон локаций, музыка в бою и рация в меню. Ход боя сам превращается в сценарий звуков. Подробности: [packages/audio/README.md](packages/audio/README.md).

## Как запустить бота

Нужны Node.js 22.18+ и Rust/WASM, подготовленные по [инструкции](LOCAL_BUILD.md#подготовка-исходников).

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Скопируй `.env.example` в `.env` и впиши токен в строку `BOT_TOKEN=`.
3. В папке проекта:

   ```
   npm install
   npm run bot
   ```

4. Напиши своему боту `/start` и подпиши контракт. Команды: `/fight` — бой с ботом, `/duel` — ссылка для друга, `/rules` — правила, `/me` — твой жетон.

Жетоны игроков хранятся в файле `data/operators.json` и переживают перезапуск. Бои пока хранятся в памяти: если перезапустить бота, текущие бои пропадут.

## Как запустить веб-клиент

Звуки и музыка берутся из `packages/audio/assets`, фигура бойца (мужская Персона) лежит в `apps/web/models/persona-male.glb`. Отдельно класть ничего не нужно:

```
npm install
npm run web
```

Открой адрес, который напишет Vite. В меню боя можно выбрать оружие и набор ветерана, станцию рации и фон. С `?cal` в адресе первым идёт кадр-сверка: фигура должна ровно закрыть нарисованного бойца.

Старый манекен X Bot можно вернуть для сравнения: `npm run assets -w @crowned-dogs/web` скачивает его, а `VITE_MODEL=models/mannequin.json npm run web` запускает игру с ним.

`npm run web:build` собирает игру в `apps/web/dist/` вместе со звуками и моделью. Папка устроена так же, как пробная арена, её можно выложить на любой статический хостинг. Звуки из набора Sonniss нельзя выкладывать отдельно от игры, поэтому их нет в репозитории: сборка берёт их из `private-audio/` рядом с клоном (подробнее в `packages/audio/README.md`), а страница с ними должна оставаться закрытой.

## Проверки

```
npm run check      # проверка типов и все тесты
npm run balance    # бот против бота для всех пар оружия, таблица побед
```

Игровая логика, состояние, расчёты движений и графики написаны на Rust и собираются в WASM. Rust также управляет экранами базы, примерочной, оружия и боя, загрузкой моделей, проходами рендера, текстурами и проигрыванием звука. TypeScript передаёт внешние API DOM, Three.js, WebAudio и Telegram; Three.js остаётся библиотекой рендера. Команды запуска и проверок автоматически обновляют WASM.

`npm run source:share` показывает долю Rust по непустым строкам рабочих исходников. Тесты, эталоны, сгенерированные файлы, зависимости и сборки в рабочую долю не входят; HTML, CSS и GLSL учитываются отдельно. Это доля исходного кода, а не производительности или выполненной работы. Для повторения замера прежней версии: `node tools/source-share.mjs --ref 9266f893ab87c5cb2c4ba7b625e68af5654c5c46` (43,41%).

## Устройство

```
crates/
  game-core/      правила боя, AI, RNG и каталог
  game-client/    состояние клиента/сервера, аудио, камера и линза
  game-motion/    IK, движение, отдача и хореография
  game-graphics/  материалы и геометрия примерочной
  game-ui/        состояния интерфейса, раскладка, тексты и лог
  game-wasm/      интерфейс для браузера и Node.js
    src/browser/ управление DOM, 3D-сценами, звуком и загрузкой в Rust
packages/core/src/   типизированные вызовы Rust
packages/core/reference/  прежняя версия только для сравнения и типов
packages/runtime/    загрузка WASM и обмен с Rust
apps/desktop/        окно Windows и локальный сервер
packages/audio/
  assets/    эффекты, петли, музыка
  src/       звуки по именам, озвучка хода, правила музыки, рация, проигрыватель
tools/audio/ сборка эффектов из пака Sonniss
apps/server/src/
  operators.ts  подписанные контракты и жетоны, файл data/operators.json
  duels.ts   живые бои, приглашения, таймер хода
  codes.ts   нажатия кнопок в коротких кодах для Telegram
  view.ts    тексты и кнопки
  bot.ts     подключение к Telegram (grammY)
  main.ts    запуск
apps/web/src/
  game/local-duel.ts  бой с ботом в браузере на правилах ядра
  arena/frames.ts     нарисованные кадры и как их камера видит пол
  arena/arena.ts      3D-фигуры в кадре: ходьба, попадания, падение, отражение
  arena/rig.ts        нужные арене кости в скелете Mixamo или UE, наклоны по осям фигуры
  audio/arena-audio.ts  звук экрана боя через packages/audio: петли кадра, рация, вкл/выкл
  hud/holo.ts         голограмма Персоны в защите
  hud/log.ts          запись боя и строка последнего хода
  hud/words.ts        что экран говорит по-русски: строки хода, итог боя
  main.ts             экран боя: кнопки, таймер, ход, меню
apps/web/models/      фигуры .glb (мужская Персона), сборка кладёт их рядом со страницей как .json
```
