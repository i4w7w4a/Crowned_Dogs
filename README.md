# Crowned Dogs

Пошаговые дуэли Персон — боевых андроидов, которыми управляют операторы. Постсоветские регионы, база в соляной шахте, бой из-за плеча с выбором атаки прямо на враге. Играть можно в Telegram, позже на телефоне и ПК.

Концепт игры (сеттинг, правила, оружие, стиль): [документ](https://claude.ai/artifact/F5ZwmpZkDkQiYptP9DvEgc).

## Что уже есть

- **Боевое ядро** (`packages/core`). Правила хода, оружие, погода, время суток, сжатие поля, таймер, бот-соперник. Все цифры баланса лежат в одном файле: `packages/core/src/rules.ts`. Ядро ничего не знает про Telegram, поэтому его же подключит будущий 3D-клиент. Сервер — единственный судья: он хранит бой и бросает кости.
- **Веб-клиент** (`apps/web`). Бой с ботом в 3D: нарисованный цех, живые фигуры, атака прямо по телу врага, музыка и звуки. Считает те же правила ядра, что и бот.
- **Telegram-бот** (`apps/server`). Новый игрок сначала подписывает контракт и получает жетон с номером вида K-417-093. Этот номер и есть ID игрока. Дальше бой с ботом и дуэль с другом по ссылке. Приказы тайные, на ход 60 секунд, кнопки прямо в чате.

## Как запустить бота

Нужен Node.js 22.18 или новее.

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Скопируй `.env.example` в `.env` и впиши токен в строку `BOT_TOKEN=`.
3. В папке проекта:

   ```
   npm install
   npm run bot
   ```

4. Напиши своему боту `/start` и подпиши контракт. Команды: `/fight` — бой с ботом, `/duel` — ссылка для друга, `/rules` — правила, `/me` — твой жетон.

Жетоны игроков хранятся в файле `data/operators.json` и переживают перезапуск. Бои пока хранятся в памяти: если перезапустить бота, текущие бои пропадут.

## Как запустить веб-клиент

Музыка, звуки и модель не лежат в git: звуки из набора Sonniss нельзя выкладывать отдельно от игры. Их кладёт в `apps/web/public/media/` одна команда. Модель она скачает сама, а папки с музыкой и звуками укажи свои:

```
npm install
npm run assets -w @crowned-dogs/web -- --music "C:\Users\qtas5\Documents\CrownedDogs\music\web-128k" --sfx "C:\Users\qtas5\Documents\CrownedDogs\sfx\arena"
npm run web
```

Открой адрес, который напишет Vite. Без `--music` и `--sfx` игра работает, просто без звука. С `?cal` в адресе первым идёт кадр-сверка: манекен должен ровно закрыть нарисованного бойца.

`npm run web:build` собирает игру в `apps/web/dist/`, эту папку можно выложить на любой статический хостинг.

## Проверки

```
npm run check      # проверка типов и все тесты
npm run balance    # бот против бота для всех пар оружия, таблица побед
```

Код написан на TypeScript и запускается Node.js напрямую, без сборки.

## Устройство

```
packages/core/src/
  rules.ts   цифры баланса: зоны, оружие, погода, карты, формулы урона
  match.ts   один бой: создание, проверка приказа, розыгрыш хода, итог
  ai.ts      бот-соперник
  rng.ts     кости с зерном: бой можно сохранить и переиграть точь-в-точь
  tag.ts     жетон игрока K-XXX-XXX
  draft.ts   приказ, который игрок собирает по одному нажатию
apps/server/src/
  operators.ts  подписанные контракты и жетоны, файл data/operators.json
  duels.ts   живые бои, приглашения, таймер хода
  codes.ts   нажатия кнопок в коротких кодах для Telegram
  view.ts    тексты и кнопки
  bot.ts     подключение к Telegram (grammY)
  main.ts    запуск
apps/web/src/
  game/local-duel.ts  бой с ботом в браузере на правилах ядра
  arena/frames.ts     нарисованные кадры и как их камера видит пол
  arena/arena.ts      3D-фигуры в кадре: ходьба, попадания, падение, отражение
  audio/sound.ts      музыка, рация в меню, звуки боя
  main.ts             экран боя: кнопки, таймер, ход
```
