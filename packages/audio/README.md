# Звук Crowned Dogs

Эффекты боя и интерфейса, фоновые петли локаций, музыка и рация в меню. Модуль работает в браузере (Telegram Mini App, позже клиент) через Web Audio.

## Что внутри

```
assets/
  sfx/       ~100 эффектов: выстрелы, попадания, щит, шаги, нож, граната, интерфейс, снаряжение
  amb/       6 петель: зал, кварталы, гроза, пыль, туман, база
  music/     7 треков Арта
  sfx-sources.json   из каких записей пака собран каждый файл и его громкость
src/
  bank.ts    все звуки по именам, плейлисты, уровни шин
  cues.ts    ход боя -> сценарий звуков (что и когда играет)
  music.ts   правила музыки
  radio.ts   фильтр «музыка из рации»
  engine.ts  проигрыватель для браузера
  files.generated.ts   длительности и подгонка громкости вариантов (пишет сборщик)
```

## Правила музыки (Арт, 27.10.2026)

- В бою играет случайный трек из трёх: The Limbo, 404 Room, In The Middle of Nowhere. Один и тот же два раза подряд не играет.
- Остальные четыре трека играют в меню, снаряжении и итогах как будто из рации в комнате оператора: узкая полоса, лёгкий хрип, шипение и небольшое эхо комнаты, тише боевой музыки на 5 дБ.
- Меню, открытое посреди боя, ставит боевой трек на паузу и включает рацию. Закрыл меню: рация щёлкает и выключается, трек продолжается с того же места.

## Как подключить

Папку `assets` нужно раздавать как статические файлы.

```ts
import { GameAudio, cuesForTurn, fightSounds } from "@crowned-dogs/audio";

const audio = new GameAudio({ baseUrl: "/audio/" });
button.addEventListener("pointerdown", () => audio.unlock(), { once: true }); // браузер включает звук только после касания

audio.music.enterMenu();                       // главный экран: рация
audio.setAmbience(["amb.base"]);

await audio.preload(fightSounds("rifle", ["sniper", "pistol"])); // у врага есть запасной пистолет
audio.music.enterFight();                      // бой: случайный боевой трек
audio.setAmbience(["amb.hall", "amb.storm"]);  // локация + погода

const inHand = [match.fighters[0].weapon, match.fighters[1].weapon];
audio.playCues(cuesForTurn(report, { viewer: mySide, weapons: inHand }));  // озвучить разыгранный ход
audio.play("ui.tap");                                      // отдельный звук

audio.music.openMenu();  // пауза боя, рация
audio.music.tune("fog-3"); // станция, выбранная из списка
audio.music.closeMenu(); // бой продолжается
audio.setVolume("music", 0.6); // ползунки настроек: master, sfx, ui, amb, music
```

Звук боя привязан к арене. Каждый ход камера смотрит, где стоят бойцы, и звук идёт с их стороны: в виде из-за плеча наш выстрел слева, враг там, где он на экране. Выстрел врага тише и глуше с расстоянием: дальний звук теряет верха. Наша атака звучит первой, вражеская на 0,6 с позже, чтобы их было легко различить.

Эхо комнаты: все звуки боя уходят в общий ревербератор. Соляной зал звенит долго (2,6 с), кварталы — коротко и тихо (открытое место). Наши звуки почти сухие, звуки врага тем «мокрее», чем он дальше. Пресеты — `audio.dsp.room` в `crates/game-client/src/dsp.rs`.

## Что когда играет

| Имя | Когда |
|---|---|
| `shot.<оружие>.near` / `.far` | наш выстрел / выстрел врага (pistol, shotgun, rifle, sniper) |
| `casing` | гильза после нашего выстрела (у дробовика нет) |
| `hit.armor` / `hit.suit` | попадание в зону с бронёй (корпус, ноги) / без брони |
| `hit.head`, `hit.crit` | слой поверх попадания в голову / критического |
| `shield.block`, `shield.break` | щит принял удар / удар пробил щит |
| `miss.near` / `miss.far` | пуля врага прошла рядом с нами / наша мимо врага |
| `knife.swing`, `knife.hit`, `knife.blocked` | нож |
| `grenade.pin`, `.throw`, `.bounce`, `.blast` | граната; взрыв приглушает музыку |
| `step`, `dash.whoosh`, `gear.rustle` | шаг, рывок, снаряжение на ходу |
| `body.fall`, `persona.powerdown`, `sync.lost` | Персона упала; у своей ещё обрыв связи |
| `persona.powerup` | Персона включилась (начало боя) |
| `ui.*` | касания, выбор защиты и шага, подтверждение, таймер, открыть/закрыть, новый ход, ошибка, соперник найден, победа, поражение |
| `loot.water`, `loot.scrap` | добыча: вода, металлолом |
| `equip.*` | надеть оружие или снаряжение; в бою смена оружия на запасное |
| `radio.on`, `radio.off`, `radio.tune` | рация: включить, выключить, сменить станцию |
| `thunder`, `helicopter.flyby`, `artillery.far` | редкие события мира |
| `amb.hall`, `amb.blocks`, `amb.base` | фон локаций: зал, кварталы, база |
| `amb.storm`, `amb.dust`, `amb.fog` | погода поверх фона |

## Как пересобрать эффекты

Эффекты собираются из [Sonniss GDC 2024 Game Audio Bundle](https://gdc.sonniss.com/) скриптом `tools/audio/build_sfx.py`: он вырезает нужные куски, слоит их, добавляет зал, выравнивает громкость и пишет MP3. Рецепт каждого звука лежит в `tools/audio/recipes.py`.

```
pip install numpy scipy soundfile pyloudnorm   # и ffmpeg в PATH
SONNISS_DIR="/путь/Sonniss.com - GDC 2024 - Game Audio Bundle" python3 tools/audio/build_sfx.py
SONNISS_DIR=... python3 tools/audio/build_sfx.py hit-armor-1 step-2   # только эти
```

Короткие удары (выстрелы, попадания, шаги) выравниваются по самому громкому моменту, всё остальное по средней громкости. Пик не выше −1 дБ.

## Лицензия

Звуки пака Sonniss можно использовать в игре бесплатно и без указания авторства. Нельзя продавать или выкладывать их отдельно от игры (как набор звуков) и нельзя обучать на них нейросети. Поэтому репозиторий и страницы для прослушивания остаются закрытыми. Музыка принадлежит Арту.
