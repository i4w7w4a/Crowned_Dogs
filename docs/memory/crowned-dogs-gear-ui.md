Art on the hangar/gear page https://claude.ai/artifact/GS1Y2g5bEKbGkUHHb74PFi (2026-10-27): "интерфейс условный же? мне нравится идея, но сам интерфейс нужно будет очень хорошо проработать потом, сейчас он перегружен и не удобен."

**Why:** the page shows every number, chart and balance table at once; it was built to check the data, not as the player's screen.
**How to apply:** treat that page as a data/balance mock only. When the real gear screen is designed, start from less: one gun large, tap a socket to see a short list, numbers on demand, Telegram phone width first. Keep the shared look from the combat UI thread (Fira Sans Extra Condensed / Fira Sans / IBM Plex Mono; cream #ece6d8, amber #e2a04a, cyan #73d3e2).
