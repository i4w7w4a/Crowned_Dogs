# «Пятиэтажки»: утро, вечер и ночь · 1 ноября 2026

Карта `blocks` теперь доступна во всех четырёх временах суток. Начало боя — 7 шагов, предел — 12. При смене карты сохраняются выбранное время и комплект. Дневной двор, его геометрия и тёмная ночь цеха сохранены. Принят `main` до `a21b1ef`, включая новые позы оружия в снаряжении.

Исходники, точные промпты и границы реконструкции — [blocks-times-art.md](../blocks-times-art.md). Файлы изображений: `apps/web/public/img/blocks-times/`, шесть PNG и шесть WebP, все 941×1672 без увеличения. Размеры и SHA256 проверены по `assets.json`.

## Проверки

- `npm run check`: 198 проверок прошли, одна прежняя проверка forced GC пропущена. Типы и все наборы рендера/движения/сцен прошли. Новые проверки покрывают затемнение боковых граней и восстановление их прежних дневных цветов, а также исходного шейдера после выключения ПНВ.
- `npm run rust:check`: 63 нативные проверки прошли, включая новые проверки поз оружия из `main`. Баланс этой задачей не менялся.
- `npm run web:build`: готовая production-сборка.
- В [gpu-cases.json](gpu-cases.json) — 13 реальных случаев на видеокарте: утро/вечер на высокой и низкой графике, тёмная ночь с ПНВ и без, проезды, возвращение к дню, ПНВ на исходном цехе и вечерняя солнечная сторона. Во всех случаях проекция активна, ошибок GPU — 0. После перебежек по двору проезд камеры — 0,908267 м. На десяти шагах ночной шанс обычного автомата — 0,365 без ПНВ и 0,51 с ним до дополнительных событий.
- ПНВ теперь сохраняет слабые детали Персоны и оружия до дневного отсечения ACES. Снимки `night-high-plain.png` и `night-high-nvg.png` показывают один ракурс без ПНВ и с ним. Физический ночной свет от надевания ПНВ не меняется.
- В основном игровом интерфейсе production-сборки через меню пройдены вечер → утро → ночь. Снимки: `evening-game.png`, `morning-game.png`, `night-game.png`, `time-menu.png`. Звук выключен, ошибки браузера отсутствуют.
- Локальный пакет: 583 проверенных SHA256 файлов, 580 игровых ресурсов возвращают HTTP200 с правильным размером, WASM отдаётся как `application/wasm`. [Отчёт](production-http.json).
