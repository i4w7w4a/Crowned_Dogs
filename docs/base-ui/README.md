# База и примерочная

Сделал Кодекс (ветка `codex/base-menu-fitting-room`), в игру перенёс Claude (ветка `claude/base-fitting-room`). Игра открывается с базы; бой запускается из неё.

## Поведение

- Стартовый экран базы использует последний тёмный референс соляной пещеры.
- Примерочная использует отдельный **пустой** фон `apps/web/public/img/base/fitting-room.webp`. На нём нет человека, андроида, манекена или интерфейса. Модель рисуется поверх прозрачным WebGL-слоем.
- Восемь слотов берутся из игрового ядра: оружие 1, оружие 2, голова, корпус, костюм, ботинки, нож, граната.
- Каталог фильтруется по совместимости слота. Второе оружие — только одноручное. Выбор сохраняется локально и передаётся в бой с ботом через `startBattle(loadout, onExit)`.
- Это доступный локальный каталог, а не серверная собственность игрока. Экономика и сетевой инвентарь не подключены.
- Просмотр 3D показывает ту же Персону, что и арена (`models/persona-male.json`), в комплекте A (`dress(model, KIT_A)`). Она стоит в боевой стойке первого оружия комплекта и держит такую же заглушку-ствол, как на арене. Броня, моды и раскраска пока не меняют вид: для этого нужны подогнанные модели. Поворот пальцем крутит модель, фон стоит на месте.
- Выбор оружия или ветерана в меню боя убирает комплект из примерочной до следующего захода с базы.
- Возврат на базу останавливает таймер, отложенные действия и отрисовку боя.

## Запуск

```powershell
npm ci
npm run web
```

Отдельной подготовки моделей не нужно: примерочная берёт Персону из `apps/web/models/`, как и арена, поэтому работает и на странице-артефакте.

## Изображения

- `salt-base.webp` — последний присланный пользователем референс, используется как фон меню.
- `fitting-room.webp` — новая генерация через встроенный ImageGen: пустая примерочная, тёмный нейтральный цветокор и небольшие тёплые источники света.
- Полный запрос и источник референса: [fitting-room-prompt.txt](fitting-room-prompt.txt).

Изображение комнаты и HTML-интерфейс — отдельные слои. Не следует запекать модель, надписи или слоты в фон.

## Точки подключения

- `apps/web/src/entry.ts` — вход, переход из базы в бой и обратно.
- `apps/web/src/base/base-screen.ts`, `base.css` — меню, примерочная, стеклянные слоты и каталог.
- `apps/web/src/base/loadout-state.ts` — безопасное чтение, проверка и сохранение комплекта.
- `apps/web/src/base/persona-viewer.ts` — прозрачный слой с Персоной из игры (загрузка через `arena/load-model.ts`).
- `apps/web/src/main.ts`, `game/local-duel.ts`, `arena/arena.ts` — перенос выбранного комплекта в бой и остановка при выходе.

Новую работу начинать с свежей ветки от `main`. Папку `apps/web/models/` целиком не заменять. Посадка каталожной экипировки на Персону остаётся отдельной задачей.
