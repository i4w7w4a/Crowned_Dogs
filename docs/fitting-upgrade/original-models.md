Источник: `C:\Users\qtas5\Documents\CrownedDogs\3d\04-armor\tripo\`. Происхождение подтверждено `tripo-log.md` в той же папке (Smart Mesh P2, экспорт от 28 октября). Это самостоятельные исходники до подгонки брони на скелет.

`pack-preview.py` сохраняет каждый буфер геометрии побайтно и проверяет его SHA-256 после упаковки. Координаты, индексы, нормали, UV, число треугольников и трансформации узлов не меняются. Текстуры уменьшаются до 2048 и кодируются в WebP q95; исходные файлы остаются нетронутыми. Полученные JSON — 6,2 / 5,5 / 6,5 МБ; загружаются только при открытии соответствующего предмета. В кадре предметы только равномерно масштабируются и центрируются для осмотра.

Команда воспроизведения для каждого предмета:

```powershell
python docs/fitting-upgrade/pack-preview.py ПУТЬ_К_ИСХОДНОМУ_GLB apps/web/public/preview/tripo-helmet.json
```

Нужен Python с Pillow. Для бронежилета и костюма используются соответственно `tripo-vest.json` и `tripo-suit-male.json`.

## Персона из ручной сцены

Файл: `../blender/CrownedDogs-Fitting-FreeEdit.blend`. SHA-256: `47938393ec23c61390b4239bfb07e5ce539263e1ef96c6867c04d473504387ab`.

Экспорт `blender/export_persona.py` включает `Каска К-6`, `Корпус Персоны`, `Голова Персоны`, `Костюм`, `Бронежилет` из коллекции `01 · Персона`. Применяются сохранённые модификаторы и трансформации; в игре нет повторной нормализации высоты и позы. Исходный Blender не пересохраняется. Экспортированная статическая сцена нужна только для примерочной; анимированные боевые модели не заменяются.

Сравнение с выданной исходной сценой подтвердило изменения геометрии корпуса, головы и бронежилета (у бронежилета 18 724 вершины вместо 18 727). Каска и костюм совпадают с исходником. Все пять частей взяты из пользовательского файла, без смешивания с прежней игровой Персоной.

GLB 4 753 924 байта, SHA-256 `ee640956cde7cc745169ef27efa297d7df0ffe8023fc3562c96c0c651267f955`. В `persona-authored.json` находятся его точные байты base64, включая текстуры. Для этого файла `pack-preview.py` не применяется.

Автомат — прежняя отдельная сборка P2; источник описан в [varyag-provenance.md](varyag-provenance.md). Её гнёзда используются для точек осмотра и готовых 3D-обвесов. Ручной наклон и ремень берутся из `user-fitting-layout.json` только для подвеса на Персоне.
