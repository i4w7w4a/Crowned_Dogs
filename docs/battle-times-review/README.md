# Проверка четырёх времён суток · 1 ноября 2026

Ветка `codex/battle-four-times` включает `origin/main` до `0ff460e`: новую проекционную базу, атлас и свежие положения оружия. Дневная карта сохранена, утро/вечер/ночь добавлены. Исходники и промпты: [battle-times-art.md](../battle-times-art.md). Точные правила: [battle-times-mechanics.md](../battle-times-mechanics.md).

## Автоматические проверки

- `npm run check`: 183 Node/WASM-проверки прошли, 1 прежняя проверка принудительной сборки мусора пропущена (требует отдельного запуска Node с `--expose-gc`). Типы и все наборы оркестрации рендера, движения и сцен прошли.
- `cargo test --locked --workspace --release`: 59 нативных проверок прошли.
- `npm run web:build`: готовая браузерная сборка.
- Пакет содержит все 12 новых PNG/WebP с совпадающими SHA256 из `assets.json`.
- Готовый production-каталог проверен по 509 игровым файлам: HTTP 200, верный размер, WASM отдаётся как `application/wasm`. [Финальный отчёт](production-http.json). Нативный сервер также прошёл проверку 507 файлов на первой упаковке до добавления диагностического hook и новой базы; при последней проверке его порт занял другой процесс, который не останавливался. [Первичная проверка native](native-http.json).

## Видеокарта и настоящий бой

[gpu-cases.json](gpu-cases.json) содержит 15 законченных случаев с реальными Arena, моделями, каталогом и ядром: четыре времени, ПНВ/без ПНВ, глушитель/без глушителя, вечерняя солнечная сторона, высокая/низкая графика и повторные переходы между ними. Все записанные случаи завершились с `ready=true`, проекционной сценой и нулём ошибок GPU. На десяти шагах обычный автомат ночью имеет шанс 0,365 без ПНВ и 0,51 с ПНВ до дополнительных событий. Глушитель сохраняет `revealedByFlash=false` после выстрела; обычный выстрел выставляет `true`.

В основной игре через её собственное меню просмотрены все четыре времени. Проверены ширины 1280, 390 и 320 пикселей; для узкого экрана уменьшены иконки/подписи новых кнопок. Ночной рывок передвинул среду на 1,318338 м; оборудование и скрытые поверхности раскрылись в объёме, а дневная подложка не появилась. Показатель взят из диагностического DOM-атрибута карты, а не из изменённого состояния игры.

Снимки `morning.png`, `day.png`, `evening.png`, `night.png`, `night-rush.png` и `time-menu.png` сняты в самой игре. Это разные реальные бои, а не пиксельное сравнение одной позы. `night-nvg-gpu.png` — отдельная служебная GPU-страница, не игровой интерфейс. Все ручные проверки были без звука.

ПНВ «Сыч» вновь доступен в каталоге, сохраняется вместе с комплектом и имеет 3D-просмотр обычного шлема. Это временная подстановка, прямо разрешённая пользователем; прочие предметы без моделей не открывались. Вручную пройден путь: каталог головы → «Сыч» → 3D-просмотр → база → бой → ночь. В настоящем боевом интерфейсе включился ПНВ и появилась соответствующая подпись условий; снимки `sych-catalog.png` и `night-nvg-game.png`.

## Границы проверки

Во время разработки служебная страница один раз остановилась с `already_borrowed` после смены качества на фоне обновлений WASM. Истинная причина первого исключения не установлена. После чистой загрузки та же последовательность высокая → низкая → высокая → вечер → день → утро → низкая и ночной ПНВ на низкой графике прошли без ошибок. Добавлены сообщения о первичной Rust-панике и освобождение служебной сцены при обновлении модуля. Это не доказательство устранения произвольных сбоев при горячем обновлении; готовая сборка не использует горячее обновление модулей.

Программа Windows использует тот же новый каталог `game`. Нативные программы запуска не менялись и повторно использованы из существующей локальной сборки. Их HTTP-сервер проверен; окно Windows-программы в этой задаче отдельно не запускалось. Реальный телефон и частота кадров не измерялись.

Изображения — 941 × 1672 в исходном разрешении генерации, без искусственного увеличения. Проекционная реконструкция предназначена для движения вдоль боевой линии, а не для свободной круговой камеры. В `main` ветка не сливалась.
