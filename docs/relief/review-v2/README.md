# Surface POM v2: результат и проверки

Доработка выполнена в `codex/pom-material-quality` на основе объединённой игры `a287e98`. Исходная рабочая папка с параллельными правками базы не менялась.

## Что изменилось

- Убрано ограничение смещения UV, которое фактически уменьшало физическую глубину при наклонном взгляде. Граница поля/UV по-прежнему проверяется; силуэт модели сохраняется.
- Направленный, точечный и прожекторный источники света получают собственный проход видимости поля высот. Окружение и общий рассеянный свет не затемняются этим проходом.
- Диапазон восстановленного рельефа металла: 1,6 мм; шлема: 1,1 мм. Для жилета диапазон 2,4 мм включает отдельно заданные швейные каналы и края лент на выбранных участках атласа.
- Плетение жилета вычисляется в пространстве модели: период 1,8 мм, диапазон высоты 0,4 мм. Оно не зависит от плотности упаковки тысяч мелких UV-островов. Фильтр плавно убирает плетение, когда оно становится мельче пикселя.
- Только авторские добавления формируют дополнительную нормаль; восстановленный из normal map компонент не применяется вторым bump-слоем.
- Исходные цветовые текстуры и GLB не редактировались. При низкой графике остаётся исходный PBR. При средней/высокой/ультра новый POM включён автоматически; `?relief=0` возвращает исходный материал, `?relief=1` явно включает новый.

## GPU-проверка алгоритма

На контрольном синусоидальном поле сравниваются двухтреугольная POM-плоскость и плоскость с реальным геометрическим смещением (256×256 ячеек). Цвет кодирует найденные UV. Проверяются углы 0°, 35° и 65°, внутренняя область поверхности без силуэтной границы. Средняя ошибка UV: 0,0000081 / 0,0000189 / 0,0000508; доля ошибок свыше трёх уровней 8-битного канала — 0 во всех трёх ракурсах.

При перпендикулярном свете ложных теней нет. При боковом свете затенено 9774 пикселя, при противоположном — 11091; смена направления меняет 25724 пикселя. Отчёт: `control-gpu.json`.

Оригинальные игровые модели проверены отдельным чтением 768×768 GPU-буфера. Во всех случаях альфа-контур совпадает полностью, ошибок шейдера нет. Результаты: `gun-gpu.json`, `vest-gpu.json`, `helmet-gpu.json`.

## Сравнения

`gun.png`, `vest.png`, `helmet.png`: слева исходный PBR, справа новый POM. В каждой паре одинаковые камера, масштаб, свет и окружение; применено ультра-качество. Снимки получены непосредственно из WebGL, без генеративной обработки и усиления разности пикселей. У жилета показан сверхкрупный план, где различимы отдельные нити; на игровом расстоянии они плавно исчезают.

Проверено также в production-примерочной на авторской Персоне и в оружейной при высокой графике. Все проверки без звука. Изменение силуэта, глубокие отверстия и нависающие детали остаются задачей геометрии/отдельного silhouette-прохода. Производительность на физических телефонах в этом этапе не измерялась.

## Воспроизведение

`npm run check`, `cargo test -p game-graphics`, `cargo test --manifest-path tools/height-baker/Cargo.toml --release --locked`.

Чистое запекание: сначала исходная команда height-baker, затем `cargo run --manifest-path tools/height-baker/Cargo.toml --release --locked -- . --details`, затем `node tools/height-baker/verify.mjs --record`. Повторное применение профиля к уже обновлённым картам запрещено самой утилитой.

Для интерактивной проверки: `npm run web`, затем `/surface-check.html`. «Контроль» → «Проверить» запускает сравнение с объёмной геометрией и тест направлений света; «До / после» показывает парные кадры.
