## 1. Что за игра и что готово

## 2. С чего начать на ПК

Нужны Git и Node.js 22.18 или новее.

```
cd C:\Users\qtas5\Documents\CrownedDogs
git clone https://github.com/code-of-stalker/Crowned-Dogs.git
cd Crowned-Dogs
npm install
npm run check
npm run web
```

`npm run check` проверяет типы и гоняет 102 теста, на момент передачи всё зелёное. `npm run web` запускает арену, адрес напишет Vite. Чтобы открыть её с телефона в той же Wi-Fi сети: `npm run dev -w @crowned-dogs/web -- --host`.

Бот: скопировать `.env.example` в `.env`, вписать токен от @BotFather и запустить `npm run bot`. Команды в боте: `/start`, `/fight`, `/duel`, `/rules`, `/me`.

## 4. Пробная арена на claude.ai

Страница: https://claude.ai/artifact/PxEDdVDNb7UTZtwBs6goxU, сейчас версия 32 (база, примерочная, настоящий «Варяг», меню без старых пояснений). Она закрытая и должна такой остаться, потому что в ней звуки Sonniss.

Это сборка `apps/web`. Чтобы обновить страницу:

1. `npm run web:build`.
2. Инструментом Artifact опубликовать `apps/web/dist/index.html` по этому же адресу и приложить файлы `assets/arena.js`, `assets/main.js` и `assets/index.css` (имена постоянные). Папки `img/`, `tex/` и модели `models/*.json` прикладывать, только если они поменялись: старые файлы на странице сохраняются.
3. `.glb` страница не отдаёт, поэтому сборка кладёт модели как base64 `.json`.

Если в локальной сессии нет инструмента Artifact, арену можно смотреть локально (`npm run web`) или выложить `apps/web/dist/` на любой закрытый хостинг.

Полезные ключи в адресе: `#fp` включает вид от первого лица (на claude.ai до страницы доходит только `#`, не `?`), `?cal` показывает кадр-сверку камеры, `?q=ultra` включает максимальную графику, `?back=` двигает камеру. Скрипты снимков экрана на Playwright лежат в файлах проекта: `crowned-dogs/web-test/` (`shot.js` один кадр, `test_web.js` целый бой, `fp-test.js` первое лицо, `tiers-test.js` уровни текстур), `crowned-dogs/arena-ui/tools/shot.js` (интерфейс). Им нужна собранная арена: `npm run web:build`, затем `python -m http.server ПОРТ` в `apps/web/dist` и адрес в скрипт.

## 7. Инструменты и лимиты

- **Tripo** (3D из картинок): только сайт studio.tripo3d.ai, план Pro до 22.11.2026, на 28.10 осталось около 4710 кредитов. Арт предпочитает «Умную сетку» Smart Mesh P2. Деталь брони стоила 125 кредитов. API-ключ не трогать. Встроенный браузер не загружает файлы с диска, для этого есть `research\tripo-upload`.
- **ChatGPT** через local-ai-dispatcher: концепты, образцы, бесшовные текстуры. Схемы оружия и обвесов ChatGPT рисовать отказывается, их делаем сами.
- **Blender**: интерфейс с Blender MCP или скрипты через `bpy` 5.2.3 как модуль Python. Скрипты из файлов проекта написаны под облачный Linux: пути внутри поправить под Windows, `.sh` запускать в Git Bash.
- **gltf-transform** 4.5.1 для игровых моделей, **Playwright** для снимков арены, **MediaPipe** 0.10.14 на Python 3.12 для захвата движений с видео.
