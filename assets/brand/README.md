# Логотип Crowned Dogs

Знак: пасть пса из двух корон. Верхняя корона перевёрнута, её зубцы стали верхними клыками, нижняя стоит прямо. Одноцветный вариант цвета кости `#E9E3D3` на тёмном `#0B0C0D`. Надпись набрана шрифтом Black Ops One и переведена в кривые, шрифт ставить не нужно.

## Что где

| Папка | Что внутри |
|---|---|
| `logo/` | Векторные файлы SVG. `maw.svg` — знак без фона, `maw-ink.svg` — тёмный знак для светлого фона, `maw-on-dark.svg` и `maw-on-light.svg` — с фоном, `lockup*.svg` — знак с надписью, `title.svg` — титул с «PMC · 2051», `avatar*.svg` — аватарки в круге. |
| `logo/maw-jaws.svg` | Знак, разрезанный на две челюсти: `#jaw-upper` и `#jaw-lower`. Для своей анимации. |
| `logo/maw-bite.svg` | Знак, который сам щёлкает челюстями (анимация внутри SVG, 43 КБ, без скриптов). Подходит для первой секунды загрузки. |
| `png/` | Готовые картинки: аватарки 640 px для бота и канала, знак 2048 px без фона, надписи. |
| `3d/crowned-dogs-maw.glb` | 3D-модель пасти, около 17 тысяч треугольников. Узлы `JawUpper` и `JawLower` вращаются вокруг общей петли сзади. Движения: `Bite` (щелчок, 2 с, по кругу), `Idle` (дыхание, 4 с), `Open` (открытие, 1 с). Тени в щелях запечены в цвет вершин. |
| `3d/build_maw.py` | Скрипт Blender, который строит модель с нуля. Размеры зубцов, колец и движения меняются в нём. |
| `loader/index.html` | Прототип экрана загрузки на three.js: пасть щёлкает, каждый щелчок двигает полоску, в конце пасть раскрывается. |

## Как пересобрать 3D-модель

```
pip install bpy
python assets/brand/3d/build_maw.py assets/brand/3d/crowned-dogs-maw.glb
```

## Как посмотреть экран загрузки

Страница грузит модель по относительному пути, поэтому её нужно открыть через локальный сервер, а не двойным щелчком:

```
npx serve .
```

Потом открыть `http://localhost:3000/assets/brand/loader/`.

Исходный концепт одноцветного знака нарисован в ChatGPT и переведён в вектор. Оригиналы лежат на ПК Арта в `Documents\CrownedDogs\art\09-logo-r2\`.
