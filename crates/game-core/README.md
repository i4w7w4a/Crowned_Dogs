# Rust: правила Crowned Dogs

Этот crate исполняет все функции прежнего `packages/core`: подбор и проверку
снаряжения, расчёт характеристик, команды игрока, бой, ИИ, случайные числа и жетоны.
Он не зависит от браузера, Three.js, Telegram или Windows. Одни исходники собираются
в нативный код и в WebAssembly.

Баланс и каталог находятся в `catalog/catalog.json`. Геометрия, звук и интерфейс
не являются частью боевых правил. TypeScript в `packages/core/reference` оставлен
только как зафиксированный эталон миграции и источник контрактов типов; игровой
код вызывает Rust через `packages/core/src`.

## Контракт

`dispatch(method, args)` принимает название исходной функции и JSON-массив её
позиционных аргументов. Возвращает исходную структуру результата или `Err` с
исходным текстом ошибки. Неуказанные необязательные аргументы — `null`.

Метод `constants` возвращает баланс, каталог и названия слотов. `constants()`
позволяет другим Rust-модулям читать те же данные без сериализации.

Функции с изменяемым RNG (`nextFloat`, `nextInt`, `roll`, `pickWeighted`) возвращают
`{value, state}`. `botOrder` возвращает такой же объект только при переданном
явно RNG; без него возвращается обычный приказ. Обвязка обновляет исходный массив
состояния вызывающей стороны. Движок использует UTF-16 в cyrb128, переполнение
`u32` в sfc32, порядок сложения и округление JavaScript для точного повтора боя.

## Проверка соответствия

`cargo test -p game-core --release` сравнивает Rust с 7512 снимками функций и
96 полными боями исходного движка. Проверяются приказы ИИ на каждом ходу,
история урона, RNG, итог, состояния щита/дыма/оружия, голые/начальные/ветеранские
комплекты, разные карты, погода и время суток. Числа с плавающей точкой допускают
разницу не более `1e-12`; дискретные результаты сравниваются точно.

Генератор эталона: `node crates/game-core/scripts/export-oracle.mjs`. Он читает
только замороженный `packages/core/reference`, а не текущую WASM-обвязку.
Не обновляйте эталон автоматически после изменения правил: сначала отдельно
проверьте, намеренно ли меняется баланс.
