# Rust: движение и расчёты визуализации

`compute(kind, Float64Array)` — пакетная граница для IK двух суставов, кватернионов,
пальцев, темпа шага, фильтрации анимационных дорожек, выделения треугольников рук,
отдачи и прицеливания от первого лица, падения, постановки рук/стоп, вспышек,
частиц пыли, поворота оружия и расстояния камеры просмотра.

`dispatch("motion.timeline", ...)` управляет сменой стоек, подготовкой атаки,
моментом выстрела/броска, освобождением руки, падением и возвратом к стойке.
Он выдаёт команды проигрывателю анимаций; сам `AnimationMixer`, GPU и объекты
сцены принадлежат внешней библиотеке Three.js.

`shaders/` содержит GLSL для пыли, сглаживания бликов и теней. GLSL исполняется
на GPU и остаётся языком шейдеров; Rust хранит/собирает исходники, но не заменяет
их фиктивной «Rust-версией».

Проверки:

- `cargo test -p game-motion --release`: достижение IK, длины сегментов,
  вырожденные входы, однократные события атаки, границы частиц.
- `node --test apps/web/test/motion-rust.test.ts`: сравнение с прежним решателем
  Three.js (80 поз), 700 кадров хореографии, 100 поворотов оружия, маска рук и
  четыре стойки первого лица. Требует предварительной сборки WASM.

`reference/` — замороженный эталон до миграции только для этих тестов. Он не
импортируется в игровую сборку.
