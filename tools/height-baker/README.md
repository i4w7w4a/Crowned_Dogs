# Карты микрорельефа оружия и брони

Этот отдельный инструмент Rust восстанавливает **приближённое поле высоты по исходным tangent-space normal maps**. Цветовые текстуры не участвуют: тёмная краска не превращается в отверстие. Исходные GLB не изменяются.

## Повторить

Из корня проекта:

```powershell
cargo test --manifest-path tools/height-baker/Cargo.toml --release --locked
cargo run --manifest-path tools/height-baker/Cargo.toml --release --locked -- .
cargo run --manifest-path tools/height-baker/Cargo.toml --example preview --release --locked
cargo run --manifest-path tools/height-baker/Cargo.toml --release --locked -- . --details
node tools/height-baker/verify.mjs --record
```

Запекатель читает `apps/web/public/preview/<модель>.json`, но не умеет распаковывать meshopt. Перед запеканием положите туда несжатые GLB (для «Варяга»: после `gltf-transform resize`, до `meshopt`), после запекания верните сжатые файлы. Материалы без normal map (хомут двойного магазина) пропускаются.

Утилита имеет собственный Cargo workspace/lock: декодер изображений не попадает в игровую WASM-сборку. Результаты — `apps/web/public/tex/relief/`, контактный лист — `docs/relief/height-overview.png`.

## Что внутри

Для 47 материалов сохранены: «Варяг» и 13 его модулей (вместе с прицелом «Сокол» и глушителем «Тишина»), «Пустельга» с 9 модулями, «Таран» с 8, «Беркут» с 10, шлем, бронежилет и костюм. Моды, собранные из простых форм (патронташи, чок, тритиевые точки), карт нормалей не имеют и пропускаются. Для каждого:

- `height.png`: рабочая линейная 8-битная карта. Нейтраль — точно 128/255.
- `height16.png`: 16-битный мастер для дальнейшей правки. Нейтраль — 32768/65535.
- `mask.png`: допустимая область с плавным затуханием у границ каждого UV-острова. Внешние пиксели и границы — 0.
- `relief.png`: рабочая упаковка RGBA, R = высота, G = маска, B = авторская добавочная высота (128 — нейтраль), A = вес плетения (по умолчанию 255). Читать без sRGB-преобразования, `flipY=false`, как исходные карты glTF.
- `manifest.json`: точные пути, имена материалов, разрешения, масштаб, настройки решателя и измерения ошибки.

Костюм помечен `eligible:false`: карта подготовлена для изучения и правки, автоматическое смещение складок и швов выключено. Для жёстких поверхностей допускается только небольшой поверхностный POM; эти карты не дают основания обещать правильный новый силуэт произвольной модели.

## Метод

1. Из исходных preview GLB читаются нормали и реальная UV-развёртка. Связность треугольников по общим UV-рёбрам определяет острова; геометрия растеризуется в маску.
2. Компоненты нормали переводятся в наклоны `dH/du=-Nx/Nz`, `dH/dv=-Ny/Nz` по соглашению glTF. Наклоны ограничены; средний наклон каждого острова вычитается, поскольку общую плоскость задаёт сама модель. Это также убирает искусственный наклон от кода нейтральной нормали (128,128,255).
3. Экранированное уравнение Пуассона решается сопряжёнными градиентами с предобусловливанием Якоби. Границы островов не обмениваются высотой; слабый штраф на высоту убирает произвольную общую форму, которой карта нормалей не определяет.
4. Рабочий диапазон определяется 99,5-м процентилем модуля высоты. Результат плавно возвращается к нейтрали за 6 пикселей до UV-границы. Отдельная маска позволяет шейдеру отвергать смещённые выборки за пределами острова.
5. Амплитуда ограничена долями миллиметра и дополнительно уменьшается для почти плоских normal maps. Слабая квантизация бронежилета не растягивается до крупных канавок.

Оружие экспортируется в метрах; масштаб каждого ствола берётся из его собственного габарита (с модами габарит «Варяга» меняется). Исходные Tripo-предметы нормализованы приблизительно к единице; предполагаемые размеры шлема 0,30 м и бронежилета 0,60 м записаны **как оценки**, вместе с `unitsPerMeter`. Шейдер должен учитывать последующий масштаб объекта. Значения амплитуды — консервативная художественная калибровка, а не восстановленный физический замер.

## Проверка и ограничения

Тесты проверяют восстановление известного интегрируемого поля и отсутствие передачи высоты между островами. Для каждого реального материала измеряются невязка решателя и угловая ошибка восстановленных нормалей на внутренней области UV. Сравнение ведётся с нормалями после удаления среднего наклона острова, до ограничения амплитуды и затухания границ.

Метрики всех 47 наборов записаны в `manifest.json`. Таблица ниже из первой записи (шесть наборов, до оружейных модулей), средняя угловая ошибка в градусах:

| Материал | Плоская поверхность | Восстановленная высота |
| --- | ---: | ---: |
| Варяг | 13,954 | 8,210 |
| Сокол | 14,826 | 8,261 |
| Тишина | 21,192 | 10,638 |
| Шлем | 1,879 | 1,357 |
| Бронежилет | 0,490 | 0,343 |
| Костюм, только исследование | 7,124 | 3,366 |

Скрипт `verify.mjs` проверяет SHA-256 197 исходных файлов, карт и манифеста, разрешения и разрядность PNG. После намеренного повторного запекания обновить запись можно с `--record`. Пример `preview` дополнительно проверяет все пиксели упаковки и нейтральные швы, затем создаёт контактный лист.

Нормаль задаёт локальный наклон, но не абсолютную высоту. Исходные карты могут быть неинтегрируемыми, иметь ошибки компрессии и не содержать крупной геометрии. Отверстия, провода, отдельные слои ткани и нависающие детали должны оставаться реальной геометрией. Результат не называется high-poly bake.

Карты для авторской Персоны подключаются только после проверки реальных UV и decoded normal pixels. Проверка записана в `aliasValidation`; одного совпадения имени недостаточно. Шлем авторской Персоны не получил alias, потому что его UV-покрытие не прошло строгий порог 98%; это не препятствует отдельному просмотру оригинального шлема.

Документация декодирования/16-битного PNG сверена через Context7: [image-rs/image](https://github.com/image-rs/image). Все расчёты и кодирование карт выполняются локально на Rust; генеративная дорисовка текстур не используется.


## Профиль v2

После восстановления из нормалей `--details` применяет отдельные профили: диапазон металла 1,6 мм (все стволы и модули), шлема 1,1 мм, жилета 2,4 мм. Швейные каналы/кромки заданы по вручную выбранным областям исходного атласа; цвет не преобразуется в высоту. У жилета рабочие карты 2048×2048. Плетение вычисляется в шейдере в пространстве модели с периодом 1,8 мм и диапазоном 0,4 мм; фильтр учитывает размер пикселя. Исходные метрики `validation` относятся к восстановленному компоненту до авторских добавлений. Повторный `--details` без чистого запекания отклоняется. Сравнения: `docs/relief/review-v2/`.
