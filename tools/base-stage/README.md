# Проекционная база и переходы

Главная сохраняет исходный `img/base/salt-base.webp`. Фотография проецируется с неподвижной камеры на отдельные объёмы: капсула, корона, стол, радио, ложементы, стены, пол и непрерывный свод туннеля. Манифест содержит **43 меша / 432 треугольника**. Карта глубины для построения геометрии не используется.

`build_stage.py` экспортирует геометрию в `apps/web/public/img/base-stage/manifest.json` и сохраняет редактируемую сцену `release-local/base-stage/CrownedDogs-Base-Projection.blend` с исходной камерой и двумя анимированными камерами. Команда из корня:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --factory-startup --python tools/base-stage/build_stage.py
```

В игре контроллер `crates/game-wasm/src/browser/home_stage.rs` двигает камеру при постоянном фокусном расстоянии:

- «В бой»: 2,55 м вперёд, с приближением к короне в капсуле, 2,1 секунды.
- «Снаряжение»: 6,8 м вперёд по дуге в обход капсулы к туннелю, 2,4 секунды.

После окончания проезда Rust-контроллер базы открывает нужный экран. Модель Персоны загружается во время проезда в туннель. Повторные нажатия блокируются. Смена маршрута и уничтожение контроллера отменяют незавершённый переход. При `prefers-reduced-motion` или недоступном WebGL экран открывается без проезда; фотографический фон остаётся доступен. В покое одинаковый кадр не рисуется повторно.

Исходная фотография остаётся основной текстурой. `clean.png` — скрытая подложка без вынесенных в геометрию предметов. Рендерер строит маску из обведённых контуров и использует подложку только там, где предмет открывает фон; цельная маска капсулы закрывает и промежутки между её деталями. `salt-wall.png` продолжает стены за пределами фотографии. Обе карты созданы встроенным imagegen по исходному изображению; оригинал сохранён. Пол за пределами фотографии использует существующую отдельную текстуру боевой сцены.

Боковины восстанавливаются приближённо. Это декорация под две заданные траектории, не полностью отсканированная локация для свободного обзора. В Blender сохранены геометрия, фотографический проектор и траектории; маска скрытого фона и переход к тайловым материалам за границей кадра исполняются игровым рендерером.

## Проверки

- `apps/web/test/home-stage.test.ts`: реальные Rust/WASM и Three.js, перемещение камеры в метрах, неизменная матрица проекции, кэш покоя и освобождение ресурсов.
- `apps/web/test/browser-dom-rust.test.ts`: ожидание завершения проезда, блокировка повторных запусков и отмена при освобождении контроллера.
- Прежние проверки боя и рендера сохраняют свою роль: новый общий проекционный материал должен проходить их без изменения эталонов.
- Браузерная проверка без звука на 1280×720 и 390×844: оба проезда, название «Снаряжение», возвращение на базу и вход в бой. Физический телефон и отдельное окно WebView2 в этом проходе не проверялись.
- `npm run check`: 170 успешных сценариев и один GC-сценарий, проверенный отдельно (`--expose-gc`: 5/5). `npm run rust:check`: 39 успешных тестов. Web и Windows-сборки прошли; локальный пакет проверен по 267 хэшам и 264 HTTP-ресурсам, включая WASM и аудиодиапазоны.

## POM в этой сборке

Подиум использует Silhouette POM. Для автомата, шлема и жилета сохранён предварительный **surface POM** с флагом `?relief=1`; по умолчанию он выключен и не меняет внешний контур модели. Новые правки из отдельного `codex/pom-material-quality` по согласованию с пользователем не включены, пока второй агент их не завершил.
